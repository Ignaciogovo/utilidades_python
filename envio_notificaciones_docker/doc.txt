=========================================================================
  enviar_notificaciones - Docker
=========================================================================

0. .env (copia esto a .env en la raíz del proyecto y editalo)
----------------------------------------------------------------------
   EMISOR_CORREO=tu_correo@gmail.com
   PASS_CORREO=tu_app_password_16_chars

   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=587

   EMAIL_GENERICO=alertas@midominio.com

   CARPETA_ERRORES=./notificaciones/
   ENVIADOS_DIR=./notificaciones/enviados/
   RETENCION_HORAS=24

   PROYECTO=mi_proyecto
   RUTA_CONTROL=./logs/control.log

1. Build
----------------------------------------------------------------------
   cd /ruta/al/repo/utilidades_python
   docker build -f envio_notificaciones_docker/Dockerfile -t enviar-notificaciones .

2. Run (one-shot, con .env + volumen persistente)
----------------------------------------------------------------------
   docker run --rm \
     --env-file .env \
     -v $(pwd)/notificaciones:/app/notificaciones \
     enviar-notificaciones

3. Cron (host, cada 5 minutos)
----------------------------------------------------------------------
   */5 * * * * cd /ruta/al/repo && docker run --rm \
     --env-file .env \
     -v $(pwd)/notificaciones:/app/notificaciones \
     enviar-notificaciones >> /var/log/envio_notificaciones.log 2>&1

4. Self-check (validar la imagen sin tocar nada)
----------------------------------------------------------------------
   docker run --rm --entrypoint python enviar-notificaciones \
     -m utils.enviar_notificaciones
   # Deberia mostrar: "enviar_notificaciones v1.1.0 OK"

5. Notas
----------------------------------------------------------------------
   - RECEPTOR_CORREO no es necesario (el daemon lo setea solo).
   - Las carpetas CARPETA_ERRORES, ENVIADOS_DIR y logs se auto-crean.
   - Con volumen bind-mount el usuario del contenedor (root) debe poder
     escribir en la ruta montada.
   - Sin pendientes en CARPETA_ERRORES, el daemon sale sin abrir SMTP.
